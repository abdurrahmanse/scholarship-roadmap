# Scholarship Roadmap

> An interactive roadmap and toolkit for securing 100% fully funded postgraduate research positions (MS Thesis & PhD) in AI and Computer Science.

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Icons**: [Lucide React](https://lucide.dev)

---

## 🧭 Key Features

- **5-Level Research Roadmap**: Structured milestones from math foundations to lab onboarding.
- **Interactive Cold Email Builder**: Dynamic cold outreach email generator for faculty outreach.
- **Applicant Diagnostic Scorecard**: Real-time evaluation of research profile and target lab tiers.
- **Net Stipend Calculator**: Cost-of-living and stipend savings analysis across global AI hubs.
- **Funded Programs Directory**: Curated database of fully funded PhD & MS Thesis institutions.
